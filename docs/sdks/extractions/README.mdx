## Overview

Alpha feature endpoints for Extractions requests

### Available Operations

* [create](#create) - Submit an Extractions request

## create

Extracts, computes, estimates or forecasts typed fields from a state string and image assets using an extraction-style System One model. Alpha: the shape is not stable.

### Example Usage

```python
from openrouter import OpenRouter
import os


with OpenRouter(
    http_referer="<value>",
    x_open_router_title="<value>",
    x_open_router_categories="<value>",
    api_key=os.getenv("OPENROUTER_API_KEY", ""),
) as open_router:

    res = open_router.alpha.extractions.create(fields={
        "contacts": {
            "items": "text",
            "type": "list",
        },
        "days_to_pay": {
            "max": 120.0,
            "min": 0.0,
            "step": 1.0,
            "type": "estimate",
        },
        "due_date": {
            "instructions": "Issue date plus the net payment days",
            "type": "date",
        },
        "invoice_number": {
            "type": "text",
        },
        "total": {
            "decimals": 2,
            "type": "number",
            "unit": "USD",
        },
    }, model="cloudflare/clairic", state="Invoice INV-2291 issued 2026-09-02, net 30. Contacts: Dana Ruiz, Priya Shah. Total $1080.", reference_date="2026-10-28")

    # Handle response
    print(res)

```
