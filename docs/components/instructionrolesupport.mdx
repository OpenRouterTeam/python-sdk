---
title: "InstructionRoleSupport"
---

How leading instruction (developer/system) messages are mapped before reaching a chat-completions provider. 'developer' keeps the developer role, 'system' downgrades developer to system, 'user-only' downgrades both to a wrapped user message. Overridable per-endpoint.

## Example Usage

```python
from openrouter.components import InstructionRoleSupport

# Open enum: unrecognized values are captured as UnrecognizedStr
value: InstructionRoleSupport = "developer"
```


## Values

This is an open enum. Unrecognized values will not fail type checks.

- `"developer"`
- `"system"`
- `"user-only"`
