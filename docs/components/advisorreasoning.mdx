Reasoning configuration forwarded to the advisor call. Use this to control reasoning effort and token budget for models that support extended thinking.


## Fields

| Field                                                                                  | Type                                                                                   | Required                                                                               | Description                                                                            |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `effort`                                                                               | [Optional[components.AdvisorReasoningEffort]](../components/advisorreasoningeffort.mdx) | ➖                                                                     | Reasoning effort level for the advisor call.                                           |
| `max_tokens`                                                                           | *Optional[int]*                                                                        | ➖                                                                     | Maximum number of reasoning tokens the advisor may use.                                |
