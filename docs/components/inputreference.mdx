---
title: "InputReference"
---

A reference asset used to guide video generation. Image references are the most widely supported; audio and video references are only accepted by providers that advertise those input modalities (including BytePlus Seedance generation 2 and newer).


## Supported Types

### `components.ContentPartAudio`

```python
value: components.ContentPartAudio = /* values here */
```

### `components.ContentPartImage`

```python
value: components.ContentPartImage = /* values here */
```

### `components.ContentPartVideo`

```python
value: components.ContentPartVideo = /* values here */
```
