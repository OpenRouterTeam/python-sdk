Reasoning configuration forwarded to panelist and analyst inner calls. Use this to control reasoning effort and token budget for models that support extended thinking.

| `max_tokens`                                                                                                                                           | *Optional[int]*                                                                                                                                        | ➖                                                                                                                                     | Maximum number of reasoning tokens each panelist and analyst model may use. Helps bound cost when models allocate too much budget to chain-of-thought. |
