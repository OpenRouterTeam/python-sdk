---
title: "XSearchOptions"
---

Enable SpaceXAI X (Twitter) search alongside native web search, with optional filters. Only applies to SpaceXAI endpoints with native search; omit to search the web only. X search is billed separately by SpaceXAI, per post and per user profile fetched.


## Fields

| Field                                                                                     | Type                                                                                      | Required                                                                                  | Description                                                                               | Example                                                                                   |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `allowed_x_handles`                                                                       | List[*str*]                                                                               | :heavy_minus_sign:                                                                        | Only include posts from these X handles (max 20). Cannot be used with excluded_x_handles. | [<br/>"OpenRouterAI"<br/>]                                                                |
| `enable_image_understanding`                                                              | *Optional[bool]*                                                                          | :heavy_minus_sign:                                                                        | Analyze images attached to matching posts.                                                |                                                                                           |
| `enable_video_understanding`                                                              | *Optional[bool]*                                                                          | :heavy_minus_sign:                                                                        | Analyze videos attached to matching posts.                                                |                                                                                           |
| `excluded_x_handles`                                                                      | List[*str*]                                                                               | :heavy_minus_sign:                                                                        | Exclude posts from these X handles (max 20). Cannot be used with allowed_x_handles.       | [<br/>"spamaccount"<br/>]                                                                 |
| `from_date`                                                                               | [datetime](https://docs.python.org/3/library/datetime.html#datetime-objects)              | :heavy_minus_sign:                                                                        | Start of the post date range (ISO 8601 date, e.g. "2025-01-01").                          | 2025-01-01                                                                                |
| `to_date`                                                                                 | [datetime](https://docs.python.org/3/library/datetime.html#datetime-objects)              | :heavy_minus_sign:                                                                        | End of the post date range (ISO 8601 date, e.g. "2025-12-31").                            | 2025-12-31                                                                                |
