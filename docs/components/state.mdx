---
title: "State"
---

The content to evaluate: a plain string, or a JSON object or array of related context.


## Supported Types

### `str`

```python
value: str = /* values here */
```

### `Dict[str, Any]`

```python
value: Dict[str, Any] = /* values here */
```

### `List[Any]`

```python
value: List[Any] = /* values here */
```
