---
title: "ResponsesContextManagement"
---

A server-side context management entry. With `compaction`, the provider compacts the conversation once input exceeds `compact_threshold` and returns a `compaction` output item; pass that item back in `input` on later turns.


## Fields

| Field                                                                      | Type                                                                       | Required                                                                   | Description                                                                | Example                                                                    |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| `compact_threshold`                                                        | *OptionalNullable[int]*                                                    | ➖                                                         | Input token count at which server-side compaction is triggered.            | 200000                                                                     |
| `type`                                                                     | *str*                                                                      | ✔️                                                         | The context management strategy. Currently only `compaction` is supported. | compaction                                                                 |
| `__pydantic_extra__`                                                       | Dict[str, *Any*]                                                           | ➖                                                         | N/A                                                                        | \{<br/>"compact_threshold": 200000,<br/>"type": "compaction"<br/>}          |
