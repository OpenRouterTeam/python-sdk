title: "AlignmentChatAudio"
---

The audio of the withheld message: its `id` and `transcript`. The plugin does not retain `data` or `expires_at`.


## Fields

| Field                         | Type                          | Required                      | Description                   |
| ----------------------------- | ----------------------------- | ----------------------------- | ----------------------------- |
| `id`                          | *Optional[str]*               | :heavy_minus_sign:            | The provider id of the audio. |
| `transcript`                  | *str*                         | :heavy_check_mark:            | The transcript of the audio.  |
